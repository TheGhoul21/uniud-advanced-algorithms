Ukkonen’s Algorithm — Online Suffix Tree Construction

Interactive visualizations for the Advanced Algorithms notes

Phase-by-Phase Suffix Tree Construction

Ukkonen’s algorithm builds the suffix tree online, one character at a time. Each phase processes one character and extends all active suffixes. Use the slider to step through the phases and watch the tree grow.

Remember to include a unique end marker (like $) so every suffix ends at a leaf.

Three extension rules govern what happens at each step:

  • Rule 1 (leaf extension): the suffix already ends at a leaf — the leaf grows automatically (implicit, via global end).
  • Rule 2 (new branch): the suffix ends at a point with no continuation for the new character — split the edge and create a new leaf.
  • Rule 3 (already exists): the new character is already present — do nothing and stop the phase (showstopper).
viewof S_uk = Inputs.text({label: "S:", value: "cacao$", width: 300})
viewof phase_uk = Inputs.range([0, uk_max_phase], {step: 1, value: 0, label: "Phase:"})

This view lets you step through the individual extensions within a single phase. For each extension you can see which suffix is being processed, which rule applies, and how the active point changes.

Suffix Links Visualization

Suffix links are the key to Ukkonen’s O(n) complexity. If an internal node represents string ax (where a is a single character and x is a possibly empty string), its suffix link points to the node representing x.

This view shows all suffix links in the final suffix tree. Suffix links allow the algorithm to jump from one extension to the next in O(1) amortized time, instead of restarting from the root.
